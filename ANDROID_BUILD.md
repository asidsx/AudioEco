# Компиляция под Android через GitHub и Capacitor

Да, вы абсолютно правы! Подключение вашего репозитория к **GitHub** даёт вам возможность настроить полностью автоматический процесс сборки (**CI/CD Flow**) сборки Android приложения (**APK**) при каждой отправке кода.

Для сборки мы используем **Ionic Capacitor** — самый современный, производительный и надёжный инструмент, который превращает веб-приложение на React/Vite в полноценное нативное Android-приложение (`.apk`).

Я уже заранее создал все необходимые конфигурации в вашем репозитории:
1. **`.github/workflows/android.yml`** — готовый сценарий автокомпиляции для GitHub Actions.
2. **`capacitor.config.json`** — файл конфигурации Capacitor, связывающий React-сборку (`dist`) с Android-платформой.

## 🚀 Пошаговый план: Как скомпилировать APK через GitHub

### Шаг 1. Экспорт кода в GitHub
1. На панели управления в веб-интерфейсе вашего редактора нажмите кнопку настроек/входа в GitHub.
2. Выполните вход (**Sign in to GitHub**) и разрешите авторизацию.
3. Экспортируйте данный проект в новый или существующий публичный репозиторий.

### Шаг 2. Запуск автоматической сборки (GitHub Actions)
Как только код окажется на вашем GitHub:
1. Перейдите на страницу вашего репозитория на GitHub.
2. Откройте вкладку **Actions** в верхнем меню.
3. Вы увидите запущенный флоу сборки с именем **Build Android App** (он запускается автоматически при первом пуше).
4. Если вы хотите запустить его вручную: выберите воркфлоу **Build Android App** слева и нажмите **Run workflow**.

### Шаг 3. Загрузка готового APK на телефон
1. На вкладке **Actions** нажмите на завершённую сборку (зелёная галочка).
2. Прокрутите страницу вниз до раздела **Artifacts**.
3. Вы увидите архив **`audiobook-player-debug-apk`**. Скачайте его!
4. Распакуйте архив, отправьте полученный файл `app-debug.apk` на свой Android-смартфон и установите его!

## 🛠️ Как это работает изнутри?

Созданный мной сценарий автосборки на GitHub Actions делает следующие шаги на облачном сервере:
1. Устанавливает Node.js и загружает все зависимости проекта.
2. Компилирует оптимизированную веб-версию плеера с помощью Vite (`npm run build`).
3. Устанавливает библиотеки Capacitor (`@capacitor/core`, `@capacitor/cli`, `@capacitor/android`).
4. Автоматически инициализирует проект Android Studio (`npx cap add android` и `npx cap sync`).
5. Устанавливает Java SDK 17 и собирает финальный проект через Gradle (`./gradlew assembleDebug`).
6. Публикует рабочий установочный файл APK в качестве артефакта сборки.

## 💻 Локальная сборка на вашем компьютере

Если вы скачаете код к себе на ПК и захотите собрать Android-приложение локально с возможностью отладки на телефоне/эмуляторе:

1. **Сборка веб-части:**
   ```bash
   npm install
   npm run build
   ```

2. **Добавление платформы Android:**
   ```bash
   npm install @capacitor/core @capacitor/cli @capacitor/android
   npx cap add android
   ```

3. **Синхронизация и открытие в Android Studio:**
   ```bash
   npx cap sync android
   npx cap open android
   ```
   *Команда `npx cap open android` автоматически запустит Android Studio с готовым к работе нативным проектом. Оттуда вы сможете запустить отладку прямо на подключенном смартфоне!*
